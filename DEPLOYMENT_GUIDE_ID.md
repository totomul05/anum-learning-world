# Panduan Memasang Anum Learning World (lewat tablet)

Semua langkah memakai browser Chrome di tablet. Tidak perlu komputer.

## A. Unggah ke GitHub (sekali saja)
1. Buka github.com, masuk ke akun Anda.
2. Tekan tanda **+** (kanan atas) lalu **New repository**.
3. Nama: `anum-learning-world`. Pilih **Public**. Centang **Add a README file**. Tekan **Create repository**.
4. Di halaman repositori, tekan **Add file** lalu **Upload files**.
5. Tekan **choose your files**, lalu pilih SEMUA berkas aplikasi sekaligus:
   `index.html`, `style.css`, `app.js`, `komponen.js`, `sw.js`, `kelas1.json`, `bab-mat-1.json`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`.
   (Penting: semuanya harus ikut. Jika ada yang kurang, mode offline tidak akan jalan.)
6. Tunggu selesai, lalu tekan **Commit changes**.
7. Dokumen `.md` (CURRICULUM_MAP, PROJECT_MASTER, NEXT_TASK, panduan ini) boleh diunggah dengan cara yang sama.

Jika tombol tidak muncul di tampilan ponsel, buka menu ⋮ Chrome lalu centang **Situs desktop**.

## B. Aktifkan GitHub Pages
1. Di repositori, buka **Settings** lalu **Pages** (menu kiri).
2. Di **Branch**, pilih `main` dan folder `/ (root)`. Tekan **Save**.
3. Tunggu 1-3 menit, muat ulang. Alamat aplikasi akan muncul, bentuknya:
   `https://NAMA-AKUN.github.io/anum-learning-world/`

## C. Pasang di tablet
1. Buka alamat itu di Chrome **saat tersambung internet**.
2. Tunggu sampai halaman tampil sepenuhnya.
3. Menu ⋮ lalu **Instal aplikasi** (atau **Tambahkan ke layar utama**).
4. Buka aplikasi dari ikon di layar utama. Lencana kanan atas akan menunjukkan Online/Offline.

## D. Uji offline (mohon laporkan hasilnya)
1. Buka aplikasi sekali saat online.
2. Matikan Wi-Fi dan data seluler.
3. Tutup aplikasi sepenuhnya lalu buka lagi.
4. Seharusnya tampil normal dengan lencana "Offline". Coba mode Orang Tua (pertanyaan penjumlahan) dan ganti nama.

## E. Memperbarui aplikasi
Unggah berkas baru dengan nama sama (Add file → Upload files), lalu Commit. Data Anum di tablet tidak terhapus. Jika tampilan belum berubah, tutup aplikasi lalu buka lagi (2 kali).
